Detailed Evaluation: TAutoCorr.R

A. Specification alignment (vs SCRIPT_METADATA_JSON)

  • Loads required dataset via relative path: load("../data/KeyWestAnnualMeanTemperature.RData")

  • Computes adjacent-year pairs: x <- temps[-n] and y <- temps[-1] (n-1 pairs)

  • Uses cor() for observed correlation (r_obs)

  • Performs permutation test by permuting the temperature series and recomputing lag-1 correlations (nperm <- 10000)

  • Computes empirical p-values from permutation distribution (one-sided and two-sided)

  • Does not use cor.test() p-value as final inference

  • Matches the required workflow and statistical method in the metadata (correlation of successive-year pairs + permutation p-value).

B. Conceptual understanding of autocorrelation

  • Explicitly frames the question as “Temp[t] vs Temp[t+1]”

  • Breaks temporal order under the null using sample(temps, replace = FALSE)

  • Reports the observed lag-1 correlation and compares to permutation distribution

  • Shows correct understanding that autocorrelation is about dependence across time lags, and that permutation provides an appropriate null for “no temporal structure”.

C. Algorithmic implementation depth (vs example solution)

  • Clear construction of lag-1 vectors (temps[-n], temps[-1])

  • Stores permutation correlations in a preallocated numeric vector (r_perm <- numeric(nperm))

  • Adds optional histogram plot + observed vertical line and label

  • Includes basic robustness checks (exists("ats"), NA filtering, length check)

  • Implementation is clean and efficient at bootcamp level (preallocation; no unnecessary recomputation).

  • Vectorisation is used where appropriate; loop is acceptable and clear.

D. Statistical & computational rigor

  • Uses Pearson correlation consistently via cor(..., method="pearson")
  • Computes empirical p-values as permutation tail probabilities:
    • One-sided: mean(r_perm >= r_obs)
    • Two-sided: mean(abs(r_perm) >= abs(r_obs))
  • This meets the “approximate p-value” requirement via permutation.
  • One minor interpretation caveat: if reporting one-sided inference, it’s helpful to state the directionality assumption explicitly (you partly do).

E. Error handling & robustness (Criterion 8)

  • Stops if ats object missing

  • Removes NA values

  • Stops if time series too short for lag-1

  • Good bootcamp-appropriate guard clauses.

  • Computes adjacent-year correlation via cor() on lagged vectors
  • Builds a null distribution via permutation
